TEMPO is a local Grok desk that schedules rewrite temperature for an AI spec. Seed H H L H. No Claude. No API key.

Ask TEMPO Clone the repo

Desk

Ask in the box. Runs entirely in the browser.

Rules

  1. Big rewrite → go low and consolidate.
  2. Tiny change and still gappy → go high and break the plateau.
  3. Never three highs in a row. Never three lows unless finishing.
  4. FINISH only after a low pass, small change, and a complete spec: system prompt, tools, and ≥5 eval arrows.
H t ≥ 0.7 diverge
M 0.4–0.7 explore
L t ≤ 0.4 converge
